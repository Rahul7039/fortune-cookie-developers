Fortune Cookie Wisdom for Developers — entry for the make.fun competition of the same name. `main.py` (Python 3.13, standard library only, no network at run time) writes one original fortune-cookie line for a software developer to `/output/entry.txt`, exactly, with no trailing newline. It is fully deterministic: two runs produce byte-identical output.

> You will fix the bug by deleting the code you were proudest of writing.

71 characters, one balanced sentence in true fortune-cookie voice ("You will...") — a truth every senior engineer recognises: the real fix is often deleting code, turned so the thing you must delete is the code you loved most. On a second read, your proudest code *was* the bug.

## Run it

```sh
python3 main.py
```
